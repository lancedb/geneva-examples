# UDF Studio sample data

Drop your own sample inputs here; UDF Studio reads from this directory (the
`--data-dir` default). Media subdirectories (`images/`, `videos/`, `audio/`,
`pdfs/`) are git-ignored — only `.gitkeep` is tracked — and `input.csv` holds
the text rows.

The canonical description of the layout, the per-modality extension rules, and
the Studio's execution contract lives at
[docs/workflows/udf-studio.md](../docs/workflows/udf-studio.md).
